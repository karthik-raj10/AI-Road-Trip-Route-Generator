# 🚗 AI Road Trip Route Generator

An AI-powered web application that generates personalized road trip plans using the **Groq API (Llama 3.3-70B)** and **Streamlit**.

## Features
- Enter a start city and destination
- Choose a travel preference (Fastest, Scenic, Budget)
- AI generates:
  - Best route
  - Estimated travel time
  - Interesting stops
  - Food recommendations
  - Travel tips

## Technologies Used
- Python
- Streamlit
- Groq API
- Llama 3.3-70B Versatile
- python-dotenv

## Run Locally

```bash
pip install -r requirements.txt
streamlit run app.py
```
