
# AI Road Trip Route Generator

A simple Generative AI web app that creates road trip plans using a HuggingFace model.

## Features
- Enter start city and destination
- Choose travel preference (fastest, scenic, budget)
- AI generates route, stops, and travel tips

## Run Locally
pip install -r requirements.txt
streamlit run app.py

## Deploy
You can deploy this project on:
- Streamlit Community Cloud
- HuggingFace Spaces

## Important
Replace YOUR_HUGGINGFACE_API_TOKEN with your HuggingFace API token.
